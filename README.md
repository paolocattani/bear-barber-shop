# BEAR Barber Shop · sito demo

Demo one-page per BEAR Barber Shop, Ponte San Nicolò (PD).

- React + Vite
- Deploy automatico su GitHub Pages ad ogni push su `main`
- Testi, servizi e orari sono segnaposto da confermare col salone

## Sviluppo

```
npm install
npm run dev
```

Il build di produzione va in `dist/` con `npm run build`.
